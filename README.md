# Daily-Report

每日自动生成并推送的「AI 原生 HR 一号位」日报，以及上海 / 江苏机会雷达。

服务对象：上海精智实业股份有限公司 HR 负责人，聚焦蓝沃 AI（工业 AI）与智能装备事业线（非标自动化）。

## 两个定时任务

| 任务 | 时间（北京） | 说明 |
| --- | --- | --- |
| 日报 `generate.yml` | 每天 07:00 | 五个模块 + 年度 HR 节奏，归档到 `reports/` |
| 机会雷达 `radar.yml` | 每天 14:00 | 扫描上海 / 江苏官方公开页面，只推新增，归档到 `radar/` |

## 日报结构

| 模块 | 频率 | 说明 |
| --- | --- | --- |
| 01 组织与人才 | 每日 | HRBP / COE / OD / TD 四视角镜头 + 每日「业务伙伴动作」 |
| 02 Agent 体系化 | 周一 / 三 / 五 + 每月 1 日 | 其余日期为 null |
| 03 经营与影响 | 每日 | M1–M4 经营语言；M5a 数据影响 / M5b 无授权影响 |
| 04 HRD 实战 | 每日；周六深度 | 影响力 / 人才发展 / 变革沟通 / 用工风险 / 领导力轮转 |
| 05 英语精进 | 每日 | 隔周周三切换为高管英语 |
| 06 认知拓展 | 周二 / 周六 | 周二业务解剖（双事业部轮换）；周六决策复盘 |

- 组织画像：`data/profile.md`（公司、双事业部、行业约束；留空字段不会编造）
- 年度节奏：脚本按月份注入 HR 日历节点（11 月 = 明年人力规划与预算）
- 行业范围：日报中的场景、案例、行业信息只围绕工业 AI 与非标自动化

## 机会雷达

- 源与关键词：`data/radar_sources.json`
- 去重库：`data/radar_seen.json`（按 URL 哈希去重，首次运行只建基线）
- 页面：`radar/YYYY-MM-DD.html` 与 `radar/index.html`
- 手动试跑：Actions → Opportunity Radar → Run workflow → 勾选 `dry_run`，只抓取打印，不写文件、不推送
- 约束：只访问 `.gov.cn` 公开页面，不登录、不绕过验证、不做代办代抢、不接返利

## 推送

在仓库 Secrets 中配置任意一个即可：

- `SERVERCHAN_SENDKEY`：Server酱（微信）
- `WECOM_WEBHOOK`：企业微信群机器人

未配置时任务正常执行，仅跳过推送。
